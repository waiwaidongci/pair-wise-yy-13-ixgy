# hxyfront-62012 色牢度检测台

纺织染整实验室的色牢度检测工作站。小样按客户订单建检测任务，订单先设必检项目与最低评级；每项记录试样方向、试验条件与两条复测评级（摩擦分干/湿）。缺项或任一项低于订单要求即保存为「待改善」并列出卡住的项目，整单报告不能生成；面料成分、配方或后整理一经变更，旧检测与报告作废，历史版本保留。列表支持按订单与状态筛选，数据存于 localStorage，重开页面可接着做。

## 分层结构

- `src/domain/fastness.ts` — 检测规则：项目目录、评级刻度、合格判定
- `src/data/archive.ts` — 批次存档：实体、版本作废、报告存档、localStorage 持久化
- `src/ui/` + `src/App.tsx` — 页面操作：订单面板、任务看板、检测录入

## 技术栈

React + Vite + TypeScript
