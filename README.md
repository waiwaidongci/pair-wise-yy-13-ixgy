# 色牢度检测台（染整实验室）

耐洗、摩擦（干摩/湿摩）、汗渍等色牢度项目按客户订单建任务、做判定、出整单报告的前端工作台。
数据保存在本机浏览器（localStorage），重开页面可继续未完成的检测。

## 业务规则

- **按订单建任务**：订单先勾选必检项目并设定每项最低评级（变色/沾色分开，预填国标默认值）；小样必须挂在订单下。
- **检测录入**：每项记录试样方向、试验条件、复测一/复测二两条评级；摩擦项目按行业叫法分为干摩（变色）与湿摩（沾色），分别评定，两条复测取低值。
- **保存即判定**：
  - 必检项目未录 → `缺项`；录了但方向/条件/复测评级缺数据 → `资料不全`；任一评级低于订单最低 → `低于要求`；
  - 有任一卡住项 → 任务保存为 **待改善**，页面列出卡住项目，**整单报告不能生成**；
  - 全部达标 → **合格**，可生成整单报告并打印 / 另存 PDF。
- **变更即作废**：面料成分、染料配方、后整理任一项修改，已提交版本的旧检测与报告标记作废（历史版本保留可查），自动开新版本、按最新订单要求重新检测。草稿阶段修改不开新版本。
- **筛选与续做**：列表按客户订单、状态筛选；展开任务可看缺项、最低分、历史版本与作废原因；筛选条件和展开项存本地，刷新后接着做。

## 代码分工

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 检测规则 | `src/types.ts`、`src/rules.ts` | 项目目录、灰卡评级、缺项/不达标判定、报告生成条件（纯函数，无 React、无存储） |
| 批次存档 | `src/archive.tsx` | 任务/版本/报告状态机、作废与开版本、localStorage 持久化、种子演示数据 |
| 页面操作 | `src/App.tsx`、`src/components/` | 筛选列表、任务详情录入、弹窗新建、报告打印 |

## 本地运行

```bash
npm install
npm run dev      # http://localhost:62012
npm run build    # 类型检查 + 生产构建
```

内置三个演示任务：一个卡在缺项与湿摩低分（待改善，且有一版因后整理调整作废的旧报告）、一个已出报告、一个刚建的草稿，可点「恢复演示」重置。
